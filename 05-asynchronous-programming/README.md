# 05 - Asynchronous Programming

In this assignment, you will build a small ASP.NET Core web app that allows you to generate and image and text based on a query.

This project works by sending HTTP requests to an image generation model (MAI-Image) and to a text generation model that are hosted on the cloud.

We will learn:

- How to check whether the ASP.NET Core web workload is installed
- How to create a web app with .NET
- How to store secrets with Secret Manager
- How to create a frontend page with a label, input, image, and button
- How to send asynchronous HTTP requests to Microsoft Foundry
- How to add a second text-generation flow using a GPT-5 model
