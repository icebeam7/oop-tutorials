# 03 - Polymorphism

In this module you will extend the game from the previous lesson to practice the most important polymorphism features in C#.

We will cover:

- Abstract classes and abstract methods (forcing subclasses to implement required behavior)
- Sealed methods (protecting an important method from being overridden)
- Sealed classes (preventing/blocking inheritance)
- Using the `protected` access modifier inside derived classes (restricting access)
- Using `is` and `as` to work with polymorphic objects safely
