# 04 - Interfaces

In this module, you will learn how to use **interfaces** in C# to define shared behavior without tying classes to a single inheritance tree.

We will cover:

- What an interface is and why it is useful
- Defining properties and methods in an interface
- Implementing interfaces in multiple classes
- Polymorphism with interfaces
- Creating a program that asks the user what object to create
- Multiple interfaces and interface inheritance
- Explicit interface implementation
