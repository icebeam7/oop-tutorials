## 01 - Project Setup

* Create a new C# Console Application named **InheritanceMinigame**.

* Inside your project folder, create a new folder named **Classes** 

* Inside the new folder, create five classes. They will represent the characters that will appear in our game:
    * Character.cs
    * Warrior.cs
    * Mage.cs
    * Goblin.cs
    * Dragon.cs
