# 08 - Challenges

[Previous: Lists of objects](07-lists-of-objects.md) | [Back to tutorial overview](README.md)

Try these challenges on your own.

---

## 1 - Create a class

Create a `Teacher` class with:

- `Name`
- `Subject`
- `YearsOfExperience`

Then create 2 teachers and print their information.

---

## 2 - Add a method

Add a method to `Teacher` called:

```csharp
public void ShowProfile()
```

This method should print the teacher’s name, subject, and experience.

---

## 3 - Use a list

Create a list of `Teacher` objects and write code to show all of them.

---

## 4 - Encapsulation

Modify a class so that values cannot be negative.

For example:

- `YearsOfExperience` should not be negative
- `Subject` should not be empty

---

## 5 - Final challenge

Create a small console application named `TeacherSystem` that allows you to:

1. Add teachers
2. Show teachers
3. Count how many teachers exist
4. Show the average years of experience

Use classes, constructors, methods, and a list of objects.
