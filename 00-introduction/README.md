# .NET + C# Console Tutorial

In this tutorial, you will build a small **Student Task Manager** Console application while practicing:

- Variables and data types
- Console input/output
- Constants
- `if` / `else`
- `switch`
- Loops
- Arrays and `List<T>`
- Methods
- Enums
- Basic input validation

## Content

| Part | Topic
|---|---|
| 1 | Create and run a .NET Console app |
| 2 | Variables, input, output, constants |
| 3 | Conditions and switch |
| 4 | Loops and lists |
| 5 | Methods and refactoring |
| 6 | Enums and final integration |
| 7 | Independent challenges |
